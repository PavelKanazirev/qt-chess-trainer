# Qt Chess Trainer 1.0.0

First complete version of the learning project.

## Highlights

- Qt 6 / QML chess board with click-to-move, feedback and an Elo rating estimate
- Puzzle selection strategies (Strategy pattern), switchable at runtime
- `TrainerService` facade shared by the GUI and both REST APIs, thread-safe
- Client REST API (port 8080) and token-protected admin REST API (port 8081)
- JSON configuration with live updates to the GUI (Observer pattern)
- PySide6 admin GUI
- CI: C++ build and 22 tests, 19 Python tests, rendered PlantUML diagrams, link check

## Known limitations

- Promotion is always to a queen
- Statistics are kept in memory and reset when the app restarts
- QML types are passed as a required property instead of registered with `QML_ELEMENT`,
  because CI runs Qt 6.4
